# scorpion-cursor
A creepy-cool animated scorpion tail that follows your mouse using HTML5 Canvas and JavaScript. 🦂

🦂 Scorpion Cursor Animation

A fun little web experiment that turns your mouse movement into a creepy-cool scorpion tail animation!

Built with HTML5 Canvas, CSS, and vanilla JavaScript, this project creates a segmented tail that smoothly follows your cursor, complete with skeletal ribs and a fading motion trail.

✨ Features
🦂 Animated scorpion-like tail that follows the mouse
🎨 Minimalist black background with white line art
🌀 Smooth movement using segment-following logic
🦴 Skeletal ribs for a scorpion-inspired appearance
💨 Fading motion trails for a cool visual effect
📱 Full-screen canvas that adjusts to window resizing
⚡ No external libraries or dependencies
🛠️ Built With
HTML5 Canvas
CSS3
Vanilla JavaScript

bash

🎮 How It Works

The animation tracks the mouse position and updates a chain of connected segments every frame. Each segment follows the one before it, creating a flexible, tail-like movement. Different line widths create a tapered appearance, while perpendicular ribs add the skeletal details.
